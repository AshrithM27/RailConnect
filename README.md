# RailConnect 🚆
### Java-Based Railway Reservation Portal

RailConnect is a Java-based railway reservation portal developed as part of my first-semester B.Tech project. It is designed to simplify railway reservation operations through a structured and modular application.

## Features

- Passenger Management
- Train Management
- Train Search
- Ticket Booking
- Ticket Cancellation
- PNR Generation
- Fare Calculation
- Waiting List Management
- Report Generation
- Exception Handling

## Technologies Used

- Java 17+
- Object-Oriented Programming
- Java Collections Framework
- Lambda Expressions
- Java Streams
- Exception Handling

## Project Modules

The application is organized into multiple modules, including:

- Passenger Module
- Train Module
- Reservation Module
- Ticket Module
- Journey Module
- Validation Service
- Search Service
- Reporting Service
- Analysis Service
